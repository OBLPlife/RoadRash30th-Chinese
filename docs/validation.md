## 与现有高清 v5 的文件操作组合

使用只读复制出的现有 `RoadRash_HD_Setup.exe`，没有修改高清项目。

| 安装顺序 | 先还原 | 结果 |
| --- | --- | --- |
| 原版 → 汉化 → 高清 | 汉化 | 保留高清 EXE/DLL；继续还原高清后 EXE、语言资源回到原版 |
| 原版 → 汉化 → 高清 | 高清 | 保留汉化资源/DLL；继续还原汉化后 EXE、语言资源回到原版 |
| 原版 → 高清 → 汉化 | 汉化 | 保留高清 EXE/DLL；继续还原高清后 EXE、语言资源回到原版 |
| 原版 → 高清 → 汉化 | 高清 | 保留汉化资源/DLL；继续还原汉化后 EXE、语言资源回到原版 |

每个组合还执行了两个安装器的重复安装。高清安装器按自己的设计保留 `RoadRashHD.ini`，汉化安装器不写它。汉化从旧版升级的路径已测；没有把高清重复安装写成已验证所有历史高清版本升级。

## 安全软件与文件方式

安装器和文字模块使用标准编译输出，无加壳、混淆、联网下载、驱动或服务。清单为 `asInvoker`，不主动提权。没有设置安全软件排除项、安装额外杀毒软件、上传用户游戏文件或更改安全策略。

发布文件未作 Authenticode 代码签名。停止改写游戏 EXE 可避免本补丁破坏其磁盘完整性，但不能保证安全软件不会对应用目录 DLL 或内存适配发出提示。原版 EXE 的 DRM、商店启动逻辑和授权检查不改。

游戏文件不使用预置整文件哈希判断版本。自身文字 DLL 的哈希只用于确认已安装模块归属，避免覆盖其他项目；发布 SHA-256 只供下载核对。安装器不会向网上发送这些信息。

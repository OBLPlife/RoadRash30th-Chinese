# v1.2.0 最终审校版

修正《暴力摩托：30周年纪念版》中文文本与显示问题，提供同一份可用于英文原版和已有汉化版的安装器。

## 更新

- 复核 1372 个非空文本条目，保留 1166 条译文体系，本轮修订 21 条语义与措辞：洗手间、旧车折价、联机房间、人物介绍和俱乐部对白等。
- 处理备用 NPC 名字、车行标题与金额显示、中文长说明排版；原版警察名称占位符 `.` 保留。
- 停止替换游戏 EXE。以应用目录文字模块配合语言资源工作，保留高清补丁及存档。
- 不使用固定整文件游戏哈希、Build ID 或商店限制。局部结构匹配时直接安装；相关结构变化时警告并允许继续或取消，确认后完整安装汉化资源和文字 DLL，不降级成部分安装。
- 窗口仅有“安装”“还原”。提供备份、重复安装、资源合并还原与中断恢复。
- 文件副本核对覆盖结构变化后接受风险的完整安装与还原，以及汉化/高清两种安装顺序、两种独立还原顺序、旧汉化/本地候选版/先前候选安装包升级、第三方同名模块保护和文件占用回滚。

## 用法

退出游戏，将 `RoadRash_ZH_CN_Setup.exe` 放进游戏根目录，双击后点“安装”。游戏语言保持英语。还原时运行同一个 EXE 点“还原”，保留目录中的 `中文补丁_安装备份`。

出现兼容性警告时，“是”表示接受提示中的风险并继续全量安装，“否”表示取消。无法完成文件读取、备份或写入等实际操作时仍会报告失败并尽可能回滚。

**还原恢复本版安装前状态；从旧汉化升级的用户会退回旧汉化。** 本版不覆盖旧 EXE 备份，也不替旧安装器卸载历史改动。

## 验证范围

用户确认本地候选版汉化正常，重新启动后开场配乐也正常。本轮未修改音乐、影片或音频逻辑。

发布封装通过离线文件副本检查。本版补入从旧汉化代码迁移的原版 EXE 错误提示翻译，并修正安装器的结构警告与继续行为。版本整理不改变文字模块逻辑。未额外运行游戏验证发布包，不宣称已覆盖全部界面、三份真实存档、联机、其他发行渠道或安全软件组合。

详见 `docs/validation.md`、`docs/coverage.md`。9 处缺乏充分依据的措辞保留原译并在审校表注明。
